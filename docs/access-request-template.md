# Research access request

Use this template when you propose a study that would use ChatDok data. Send it to **hello@chatdok.com** with the subject line `Research access request`.

A request is the start of a conversation, not an application that is granted or refused automatically. Whether and how data can be made available depends on the study, data protection requirements, the permissions that apply to the data, and any necessary ethical approval.

**Please do not send personal data about patients with your request.**
